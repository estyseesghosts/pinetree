## Failures / lessons (all script/rig-side, no product bugs)

- Seed took 4 runs: (a) assumed full-mesh delivery but interop test
  unfollows everything → edge-aware expectations; (b) this Misskey packs
  no `uri` on notes → canonical `http://127.0.1.1/notes/<id>` + `ap/show`;
  (c) mk `notes/renotes` needed polling (async queue, Announce logged on
  receipt); (d) followers-only lives in HOME not global timeline;
  mention-addressed notes surface via notifications on pinetree.
- Toolchain: never `node <shim>` a `.bin/vite` (exec it); never pass the
  WSL Windows-junk `PATH` through `env` (breaks on spaces) — use a clean
  minimal `PATH` with `/usr/sbin` first for Node 22 work.
- Observed, not chased: Sharkey log shows a duplicate-key `user` INSERT
  race under concurrent remote-user creation, and `nodeinfo https://`
  fallback WARNs for `127.0.1.5` (http-only loopback env) — both benign here.
- mk-proxy limits (documented, still true): no WS forwarding (streaming
  dead through :8182 — use direct :3000 WS, proven by STREAM_OK), no
  `/sw.js`, `/api/{stats,charts/*}` 404s. Misskey UI shows sign-in via the
  `/login` helper (no `signin-flow` in pinetree).
