# state/ — work logs

Append-only. One file per work session: `logs/YYYY-MM-DD-<topic>.md`.

Each entry records:
- Goal and phase reference (proposal section).
- What changed (files, contracts touched).
- Evidence (test commands + real output, or `not yet verified`).
- Open questions and next step.

Never edit or delete past entries. Supersede by writing a new entry that references the old one.
